# KMS Examination Management System (EMS)

A frontend-only management prototype for the **KMS College of IT and Management, Dasuya** MST examination workflow.

## Prototype scope

This milestone intentionally uses local fictional demo data only. It demonstrates the relationship between college master student records, Google Form staging/imports, exception review, approval, and admit-card preparation. It does **not** include authentication, database persistence, Google integrations, PDF generation, or file storage.

## Run locally

```bash
npm install
npm run dev
```

## Included screens

- Dashboard and session overview
- Master students and filters/bulk selection
- Needs Attention exception review queue
- Student profile
- Google Form import pipeline preview
- Admit card management and operation preview
- Administration/configuration preview
